# PlantCoordination

A tool to register your indoor and outdoor plants.
Has a dictionary of different plants and their needs. Needs include: light, watering, optimal soil traits, optimal soil composition, plant food.
You can add your own notes to each registered plant.
You can add a photograf of your plant. 
There is a timline including: watering, feeding, repotting, date of aquisition, new photographs, height, pot size, used soil and ingredients with percentage.

For the desctop/web application the view of a single plant is designated by the size of the device. For mobile devices all informations are sorted top down, begining with the latest picture. For desctops the view is like a ..., with the latest photograph on the right side.

Plants have needs, current potsize, soil composition, drainage, last watering, last feeding, how much light the plant is getting (indirect, direct sunlight, shade),
